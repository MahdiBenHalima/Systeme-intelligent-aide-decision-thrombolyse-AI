# Système intelligent d'aide à la décision pour la thrombolyse

Composant **Machine Learning** d'un système intelligent d'aide à la décision pour la thrombolyse.

Ce repository public présente la partie IA/ML du projet sous une forme reproductible et sans données médicales réelles.
